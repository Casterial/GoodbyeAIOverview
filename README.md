# Google Auto `-ai`
Finds a way to hide the dumb AI overview

## Features
- Works from the browser address bar.
- Works when searching directly on Google.
- No permissions required.

## Why?
Google AI overview always appears above the traditional search rersults and interferes with the traditional way of browsing. The information provided by the AI overview can often provide incorrect information, bad links, or be in the way of the actual answer.

## Compatibility
- Vivaldi
- Google Chrome
- Microsoft Edge
- Brave
- Opera

## Installation
1. Download or clone the repository
2. Open your browser's extensions page.
3. Enable **Developer Mode**.
4. Click **Load Unpacked**
5. Select the extension folder.
